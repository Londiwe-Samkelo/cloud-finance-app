# cloud-finance-app - Cloud Computing Project

## What is this?
A cloud-based application built on AWS that demonstrates core cloud computing concepts including storage, serverless functions, and deployment. The app processes and stores financial data in the cloud. 

## Why I built this
I am an aspiring developer working towards a career in FinTech. This project explores how cloud infrastructure powers modern financial applications - from storing transaction data securely to processing it at scale. 

## Tech stack
- AWS S3 (storage)
- AWS Lambda (serverless functions)
- AWS API Gateway
- Python
